# 中文使用指南

[返回首页](<../README.md>) · [构建与开发](<BUILDING.md>)

## 环境与启动

- Windows 10/11 x64。
- 系统需支持 DirectX 11；硬件设备不可用时程序尝试 WARP 软件渲染。
- 使用 Windows 系统中文字体，不要求安装 Python、Qt 或浏览器。
- 解压 Release 运行包后启动 `HLLCalc.exe`。源码构建的便捷入口为 `build/HLLCalc.exe`。

首次启动默认显示计算器并启用独立准星。准星是透明、鼠标穿透且不激活的置顶窗口；主界面收起不影响它。

## 呼出、收起与退出

默认全局快捷键为反斜杠 **`\`**。

- 按一次收起计算器，再按一次置顶显示并将键盘焦点放到距离输入框。
- 呼出时记录之前的前台窗口和鼠标位置；收起时尝试归还焦点、恢复鼠标位置。
- 右上角 `×`、最小化按钮、收起按钮和普通状态下的 `Esc` 都只隐藏界面。
- 彻底退出请点左下角“退出程序”，或右键托盘图标选择“退出程序”。准星会一并关闭。
- 默认不占用减号，可以直接输入负倾角；也可使用输入框旁的 `±` 按钮。

Windows 前台切换策略、游戏权限和输入捕获模式可能影响焦点及鼠标表现。程序不会通过游戏注入、输入宏或修改内存强行兜底。

## 自定义快捷键

打开左侧“快捷键设置”。

### 录制

1. 点“点击录制新快捷键”。
2. 如需组合键，先按住 `Ctrl`、`Alt`、`Shift` 或 `Win`，再按主键。
3. 支持的绑定会立即生效并自动保存，下一次启动继续使用。

单独按修饰键不提交；录制时 `Esc` 取消，不会收起计算器。录制用的那次按键不会触发收起。离开设置页、应用失焦或收起窗口时会取消未完成的录制。

### 手动选择与冲突

若按键被系统或其他程序拦截，录制可能收不到事件，可以在下方勾选修饰键、选择主键，再点“应用所选快捷键”。

- 新快捷键无法注册或保存失败时，原绑定保持不变。
- 启动时保存的绑定被占用，程序仍可使用，进入快捷键设置换键即可；也可通过托盘打开界面。
- F12、单独修饰键和部分系统保留组合不支持。
- “恢复默认”设置为无修饰的 `\`。
- 单键会在全局被占用，建议避免游戏移动键和编辑常用字符。

## 火炮计算

选择德军、美军、苏军或英军，输入正整数距离。

- **自行火炮 SPG**：使用距离与车体倾角，倾角单位为 **MIL，不是角度 °**。
- **常规火炮 STD**：只使用距离，倾角输入禁用。
- 输入或选择变化后实时更新结果；无需额外点击计算。
- 参考表共 11 行，覆盖目标距离前后各 15 米，每行相差 3 米；目标行高亮。
- STD 超过 1600 米提示射程限制。
- SPG 射角范围为 -89 至 466 MIL，英军上限为 356 MIL；不额外套用 STD 的 1600 米限制。
- 舍入采用恰好一半取偶数；距离不大于零的参考行不生成有效射击参数。

这里使用游戏辅助计算的经验参数，不是现实火炮弹道求解器。游戏更新、炮位及实际条件变化后，请重新核对适用性。功能与参数参考记录见 [第三方及来源声明](<../THIRD_PARTY_NOTICES.md>)。

## 自定义准星

在左侧“自定义准星”修改参数，外观即时应用。点“保存配置”持久化；收起或退出时也会保存。

支持：

- 中心点：方形、圆形、菱形，或关闭。
- 十字：完整、T 向下、T 向上、仅左右、仅上下，或关闭。
- 圆环、黑色描边、RGB 颜色与整体不透明度。
- 长度、粗细、间隙（包括负间隙）、中心点和圆环尺寸。
- 旋转、全局缩放、水平/垂直偏移、显示器选择。
- 自定义下落标尺与 INI 预设导入/导出。

右侧预览保持居中，屏幕偏移只作用于桌面准星。预览随界面缩放，实际叠加层尺寸以屏幕像素为单位。若设置区内容较多，可在卡片内滚动。

### 下落标尺

例如：

```text
100:30,200:70,300:120
```

冒号前为标签，后为相对中心的像素偏移；正数向下，英文逗号分隔，最多 32 项。标尺只是用户定义的刻度，不自动推导武器弹道。

### 看不到准星时

检查“启用准星”、不透明度、当前显示器、偏移、缩放及图形组件开关。透明度为零，或所有可见组件均关闭时，准星可以处于启用但不可见的状态。

## 导入 CS / CS2 基础准星

入口：**自定义准星 → 预设与保存 → 导入 CS 准星代码**。

1. 从 CS 复制完整分享码。
2. 在弹窗直接粘贴，或点“从剪贴板粘贴”。若自定义快捷键占用了代码字符，建议使用粘贴按钮。
3. 点“导入静态准星”。校验通过后立即应用并保存；之后仍可微调。

支持：

| 格式 | 范围 |
| --- | --- |
| `CSGO-xxxxx-xxxxx-xxxxx-xxxxx-xxxxx` | 18 字节，传统 v1/v3/v4 |
| `CS` 加 44 个 base57 字符，总长 46 | 32 字节，新版 CS2 v1 |

仅转入颜色、中心点、线长、粗细、间隙、T 型、透明度和描边等基础静态外观。所有样式按静态十字或 T 型处理，**不模拟动态扩散、移动、开火、后坐力和武器间隙**。导入重置旋转、缩放和偏移，关闭本地圆环、标尺，保留显示器选择。

### 换算限制

- 传统 v1 按 480 行 HUD 参考与近似间隙修正换算；像素格式按当前显示器高度与代码参考高度的比例换算。
- 使用整数像素，并受本软件尺寸范围限制；不是 CS 引擎的逐像素复刻。更改显示器分辨率后如需重新换算，请再次导入。
- 描边使用黑色，不还原新版自定义描边颜色；半描边近似为完整描边。
- 不导入瞄准镜准星和作用域专用参数。
- 格式、版本、字符、宽度或校验失败会提示错误，不修改当前准星。校验和不是安全认证。
- 合法代码本身可能没有可见线段或使用零透明度，导入后也可能不可见。

弹窗打开时仍支持当前全局快捷键收起。再次呼出会关闭遗留弹窗，并回到距离输入框。

## 版本、语言与动画

侧栏下方显示 `v版本号`，点击进入“设置与更新”。版本来自构建/tag，与 EXE 文件属性一致。

- 界面语言支持 **简体中文 / English**，首次按 Windows 界面语言选择，之后以用户保存的选择为准。切换立即生效，不需要重启。
- 正文增大为 18 单位，辅助文字约 14 单位；卡片与页面间距相对紧凑，窄窗口仍可滚动。
- 页面切换采用三次缓动淡入；按钮悬停和按下使用指数平滑颜色变化与轻微视觉收缩，不改变点击区域。
- 呼出/收起主窗口采用约 200/160ms 三次缓动淡入淡出，快速反向切换从当前进度继续；准星不参与该动画。
- “启用非线性动画”开关同时控制上述动效并保存。自动化桌面测试会暂时抑制动画以稳定定位，不改用户偏好。

## 应用内更新

更新来源为 [Arrocean/HLLCalc](https://github.com/Arrocean/HLLCalc/releases)。在“设置与更新”点击“检查更新”，网络请求在后台完成，不阻塞界面；仅检查正式稳定版。

1. 找到较新版本后点“下载更新”。程序不会未经点击就下载或安装。
2. 下载对应 Windows x64 运行包及 `SHA256SUMS.txt`，校验 SHA-256、ZIP 结构、文件路径、x64 PE 和嵌入版本信息。
3. 准备完成后点“安装并重启”，再次确认后先保存配置并退出当前实例。
4. 本地更新助手等待退出，在原目录备份/替换程序及受控许可、文档文件，启动新版本。新版本成功渲染首帧后确认；启动或替换失败会尝试回滚。

配置保存在 LocalAppData，不会随安装被覆盖。应用所在目录需要可写；只读目录或不受支持的路径可改为手动下载完整 Release 包。ZIP 解包使用系统 Windows PowerShell/.NET，不执行下载包内脚本。

SHA-256 来自同一个 GitHub Release，只用于完整性校验，**不等同于独立代码签名**。尚未发布带约定附件的新版本、网络不可达或 GitHub 限流时会提示错误；不会把检查失败当成“已是最新版本”。实际线上更新依赖仓库正确发布版本及附件。

## 配置与图标

配置自动保存在：

```text
%LOCALAPPDATA%\HLLCalc\settings.ini
```

分别使用 `[Calculator]`、`[Crosshair]`、`[Hotkey]` 和 `[Appearance]` 节；后者保存 `Language=zh-CN/en-US` 与 `Animations=1/0`。默认快捷键的值为 `Binding=0,220`。推荐使用界面修改配置。

图标由用户提供，多尺寸图标已嵌入程序，用于文件、窗口/任务栏和托盘，运行时不需要外置图片。若 Windows 仍缓存旧图标，可刷新文件夹，或取消固定后重新固定新版程序。

## 游戏兼容性与范围

请优先使用无边框窗口或窗口模式。普通桌面置顶窗口不保证覆盖独占全屏、系统安全桌面或特殊合成层。若游戏以管理员权限运行，请注意双方权限差异。

本工具不读取、不注入、不修改游戏进程，不提供宏或自动瞄准。外部准星是否允许由游戏及服务器规则决定，**不承诺反作弊兼容性**。程序按现状提供，不保证参数对每次游戏更新持续有效。

当前不包含地图浏览、手机控制、网页创意工坊、图片准星、动态响应、非对称四臂独立配置、每元素独立颜色、其他工具的分享码或军衔统计。当前提供简体中文与英文，暂不支持外置翻译包。
